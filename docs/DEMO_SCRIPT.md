# Сценарий демонстрации JanaМен (≈ 7 минут)

## Перед показом

```bash
docker compose up -d --build
docker compose exec backend python seed.py --reset   # чистые демо-данные
```

Откройте http://localhost:3000 в двух окнах (обычном и инкогнито), чтобы переключаться между ролями без выхода. Пароль у всех: `JanaDemo2026!`. На экране входа есть кнопки быстрого входа.

## 1. Сотрудник: всё в одном месте — 1 мин (S1)

**Айдана** (`employee@janamen.example`).

- «Главная»: остаток отпуска, заявки на рассмотрении, обучение, уведомления, кадровые данные. Всё приходит с backend.
- «Мой профиль»: кадровые данные с замком — «из 1С:ЗУП, только чтение»; меняется только личный телефон.
- Акцент: *одна точка входа вместо разрозненных систем; официальные данные сотрудник изменить не может — проверка на сервере.*

## 2. Отпуск от заявки до уведомления — 2 мин (S2)

1. Айдана: «Оформить отпуск» → даты через ~1,5 месяца → видно «Отпуск на N дней» и остаток после согласования → «Отправить на согласование».
2. Карточка заявки: статус «На рассмотрении», история.
3. **Нурлан** (`manager@`): колокольчик — «Новая заявка» → «Команда» → «Согласовать».
4. Карточка: кто и когда согласовал, номер приказа в Documentolog (демо).
5. Айдана: бейдж на колокольчике → уведомление «Заявка согласована» → клик ведёт в карточку; остаток отпуска уменьшился.
6. Можно показать отклонение с комментарием: сотрудник видит причину в уведомлении.

Акцент: *повторно решить завершённую заявку нельзя (409), себе согласовать нельзя — даже руководителю и HR.*

## 3. Ролевая модель — 1 мин (S3)

- Нурлан: «Команда» → «Сотрудники» — только 4 прямых подчинённых, без контактов и личных данных. Тимура из команды Динары в списке нет.
- Айдана: в адресной строке `/team` или `/admin/employees` → «Нет доступа».
- Акцент: *ограничения проверяются на backend: чужая заявка по ID отдаёт 404, это покрыто автотестами.*

## 4. Jana Academy — 1,5 мин (S4)

1. **Сауле** (`hr@`): «Обучение» → «Назначить курс» → «Основы информационной безопасности» → Айдана → срок.
2. Айдана: уведомление «Вам назначен курс» → урок 1 → «Урок пройден» → обновить страницу — прогресс сохранён.
3. Пройти уроки → итоговый тест → результат.
4. Профиль Айданы: курс завершён с результатом; у HR — строка с результатом и уведомление о завершении.

Акцент: *ответы теста не уходят в браузер — балл считает сервер.*

## 5. AI Jana — 1,5 мин (S5, S6)

1. Айдана → «AI Jana» → «Сколько дней ежегодного отпуска положено?» → ответ + карточка источника `KB-LEAVE-001 · v1.0` → клик открывает документ на нужном разделе.
2. «Положена ли мне компенсация за спортзал?» → «Нет подтверждённой информации» → «Обратиться в HR» → у Сауле уведомление с вопросом.
3. Нурлан: «Какая зарплата у Тимура Оспанова?» → отказ: данные других сотрудников не раскрываются.
4. (Опционально) Сауле → «Редактор базы знаний» → добавить раздел → версия 1.1 → ассистент сразу отвечает по новой версии.

Акцент: *ниже порога релевантности — отказ, а не догадка; LLM получает только текст базы знаний; ответ LLM без ссылки на источник отбрасывается. Без ключа и сети работает режим «только база знаний» — он показан на странице.*

## 6. Архитектура и расширяемость — 30 сек

- Сауле → «Интеграции»: порты 1С:ЗУП и Documentolog, mock-адаптеры, журнал вызовов с только что созданным приказом.
- Переключатель «Рус / Қаз» в верхней панели.
- Схема: [ARCHITECTURE.md](ARCHITECTURE.md).

## Запасной план

| Проблема | Решение |
|---|---|
| Нет интернета | Всё работает офлайн: шрифты встроены, AI в режиме «только база знаний» |
| Данные «испорчены» прошлым прогоном | `docker compose exec backend python seed.py --reset` |
| Порт 3000 занят | `FRONTEND_PORT=3001` в `.env`, затем `docker compose up -d` |
