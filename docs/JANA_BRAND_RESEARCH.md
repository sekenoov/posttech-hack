Официального брендбука нет. Документ разделяет **подтверждённые наблюдения** (взяты из публичных материалов 2026-10-17) и **дизайн-решения** команды для внутреннего продукта JanaМен.

## 2. Подтверждённые наблюдения

### Цвета (из CSS сайта)

| Переменная на сайте | Значение | Где используется |
|---|---|---|
| `--color-primary` | `#008C00` | Основной зелёный: иконки, статистика, акценты |
| `--color-primary-text` | `#12151A` | Основной текст, тёмные иконки |
| `--color-secondary-bg` | `#F6F6F6` | Вторичный фон секций |
| логотип (SVG fill) | `#1B8918` | Буквы логотипа в шапке |
| частые значения в CSS | `#18A957`, `#10B981`, `#F7F6F3`, `#F0FDF4`, `#EFFBF4` | Вспомогательный зелёный, тёплый светлый фон, светло-зелёные подложки |
| частые значения в CSS | `#5E5E60`, `#DFDFDF`, `#B3B3B6` | Вторичный текст, разделители, неактивные элементы |
| частые значения в CSS | `#F04E23`, `#ED1834` | Ошибки / предупреждения |

### Типографика

- Сайт: `font-family: Inter, system-ui, sans-serif`.
- Презентация: жирный гротеск, заголовки КАПСОМ, зелёный для акцентных слов и цифр.

### Логотип

- Wordmark **JAŃA** с акутом над N и подписью **POST** снизу, зелёный `#1B8918`; на тёмном фоне — белый.
- Файл извлечён из inline-SVG шапки сайта без изменений: `docs/assets/jana-post-logo.svg` (77×40).

### Характер интерфейса сайта

- Светлый фон, много воздуха, крупные числовые акценты («1000+ филиалов», «3+ млн»).
- Скругления: Tailwind `rounded-xl/2xl` (12–16 px), есть pill-кнопки.
- Иконки — линейные, монохромные (зелёные или почти чёрные).
- Tone of voice: «Мы…», короткие утверждения, ценности — **Открытость, Надёжность, Результат**.

## 3. Расхождение с предварительной палитрой из ТЗ

Предварительные токены из внутреннего ТЗ команды (`#158447`, `#096338`, `#A8F235`, ...) — гипотеза на случай недоступности сайта. Сайт доступен, поэтому основой берём реальные значения: `#008C00` / `#12151A` / `#F6F6F6`. Лаймовый `#A8F235` на сайте не встречается — не используем.

### Компоненты

- **Кнопки:** сплошная заливка `--jm-primary-strong`, радиус 10 px, без градиентов и подъёма при hover (текущая тема WorkHub использует градиенты — убираем ради спокойного корпоративного вида).
- **Карточки:** белые, граница 1 px `--jm-border`, радиус 14 px, тень минимальная.
- **Sidebar:** белый, активный пункт — подложка `--jm-primary-soft`, текст `--jm-primary-strong`, иконка `--jm-primary`; логотип Jana Post + wordmark «JanaМен».
- **Статусы заявок:** чипы с мягкой подложкой — pending (янтарный), approved (зелёный), rejected (красный), cancelled (серый).
- **Иконки:** MUI Icons Outlined/Rounded — линейные, монохромные, как на сайте.
- **Числовые акценты:** остаток отпуска и прогресс курса — крупные цифры зелёным, как статистика на сайте и в презентации.
- **Шрифт:** Inter 400/500/600/700, кириллица и казахские символы (ә, ғ, қ, ң, ө, ұ, ү, һ, і) поддерживаются.

### Использование логотипа

- Используем файл с сайта без перерисовки, с сохранением пропорций 77:40.
- Название продукта «JanaМен» — текстовый wordmark Inter 700 рядом с логотипом, не стилизуем под логотип Jana Post.
- Favicon — производная от логотипа (квадратный кроп буквы «J» на зелёном) помечается как временная до получения официального ассета.
- Логотип Jana Post в прототипе применяется в рамках хакатона, организованного Jana Post. Для продакшена нужен официальный файл от бренд-команды.

## 5. Чего не делаем

- Не копируем маркетинговый сайт: никаких hero-баннеров и каруселей во внутреннем продукте.
- Не утверждаем, что палитра официальная — это реконструкция по публичному CSS.
